# Pen Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship Pen, a phase-1 code editor: open a folder, edit files, save, find, and follow clean external writes, drawn by Rune, feeling like a pen on paper.

**Architecture:** The UI thread only builds the Rune view and applies keystrokes to a `ropey` buffer. Disk and file-watch run on Tokio and publish a snapshot. Rune is the GPU UI framework (wgpu, its own text and layout). It fills the same role as Electron and is not a webview. Do not introduce HTML, CSS, or a browser engine.

**Tech Stack:** Rust 2024, Rune pinned to a `dev` rev (never the branch), `ropey`, `ignore`, `notify`, `tokio`, `thiserror`, `serde` / `serde_json`. MIT.

**Spec:** This file is the spec. Confirmed 2026-11-10: phase 1 is the editor only; agents stay outside the process; plugins are later WASM; git UI is a later phase; defaults are monochrome; the product name is Pen.

## Global Constraints

- Product name is **Pen**. Window title, about string, and binary name are `pen` / `Pen`. No other name in UI copy.
- Phase 1 crates: `buffer`, `project`, `highlight`, `app`. No `git`, `lsp`, `plugins`, or `acp` crate. No traits, hooks, or config flags reserved for them.
- Rune is a git dependency. Record the pinned rev in the commit that adds it. Do not set `branch = "dev"`.
- Offline. No network calls at runtime. No telemetry.
- Platforms: macOS, Windows, Linux, via Rune. Do not add a web target.
- UI thread never awaits, and never calls `std::fs`, git, or the watcher.
- One caret. No multi-cursor, minimap, terminal, snippets, or LSP.
- UTF-8 only. A file that is not valid UTF-8 opens as a read-only notice, not a best-effort decode.
- Themes: **Ink** and **Paper** only, plus a JSON theme file. Chrome is black and white. Syntax is a five-step ink ramp unless the file supplies colors that pass contrast.
- Motion: no animation on palette open, tab switch, or caret move. Pane motion is a critically damped spring (bounce 0, response 0.35s). Reduced motion fades opacity and does not transform.
- Copy: sentence case. No tracked capitals, no eyebrows, no emoji icons, no invented metrics.
- Focus ring appears on focus with no fade-in.
- The only destructive phase-1 action is saving. Save writes a temp file in the same directory, then renames over the target. If the write fails, the original file is untouched.
- Repo root: `/Users/aj/Developer/Projects/pen`.

## Design — the nib

Pen should feel like a premium pen on paper, from the first window. Silk is continuity and weight, not blur, bounce, or a script face. The page is the product. Chrome gets out of the way.

- **Signature:** a wide left margin (48pt) before the line numbers, like a notebook page. The code does not touch the window edge.
- **Surfaces are solid.** Paper and ink, not stacked glass. A hairline rule separates sidebar and page. Do not use a frosted toolbar.
- **Ink:** ground `#12110f`, text `#f4f1ea`. Faint text must measure at least 4.5:1. Start at `#a8a49c` and move it toward the text color until it passes.
- **Paper:** ground `#f6f4f0`, text `#1a1916`. Faint text must measure at least 4.5:1. Start at `#5c5954` and move it toward the text color until it passes.
- **Selection:** foreground at 12% over the ground. Not blue.
- **Caret:** 1.5px ink stroke. It moves instantly. Blink is allowed. Under reduced motion the caret is steady.
- **Rules and focus:** 1px ink at 20% for rules, 1px solid ink for the focus ring. The ring appears instantly.
- **Radius:** 0 on the writing surface. 6px on chrome controls only.
- **Type:** IBM Plex Sans for chrome, IBM Plex Mono for code. Both OFL, bundled under `assets/fonts`. Code is 13px, line-height 1.55, tracking 0. UI labels 13px, sentence case. No italic word inside a roman title. No third family. No script face.
- **Syntax ramp:** five OKLab lightness steps of the foreground. No hue in the default themes.
- **Accent:** none unless a theme file sets one that passes 4.5:1 on the ground. Otherwise ignore it.
- **Motion ingredients:** pane spring bounce 0, duration 0.35s, using Rune's spring. Button press is `scale(0.98)` plus opacity, 100ms, ease-out `cubic-bezier(0.23, 1, 0.32, 1)`, on pointer-down, and only for a fine pointer. First launch only: the empty page fades in over 200ms. Every later launch is instant. No ink trail on the caret. No keystroke sound.
- **Empty page copy:** the action is "Open a folder". Nothing else on that screen.
- **Not in phase 1:** a download page, a splash logo, an installer wizard. The binary is the download. A Hallmark page for the download is a separate run, and it must use this same Ink / Paper pair.

## Review Focus

- A file changes on disk while the buffer is dirty. Keep the user's text. Do not overwrite. Show a one-line conflict.
- A 10 MB UTF-8 file opens. First paint shapes the visible window only, not the file.
- An IME preedit is cancelled before confirm. The rope does not keep the preedit, and undo does not replay it.
- A theme file sets an accent or a syntax color under 4.5:1 on the ground. That color is dropped. The ink ramp is used.
- Reduce Motion is on. Opening the sidebar changes opacity only. It does not translate.
- Save cannot create its temp file. The original file is still the old bytes.
